# 도담 추천 태그 체계

Point와 Experience에는 아래 태그를 함께 사용한다. 태그는 추천 후보를 좁히는 보조 신호이며, 실제 추천에서는 사용자 GPS 거리와 이용 가능 시간을 우선 반영한다.

| 축 | 태그 | 활용 예 |
| --- | --- | --- |
| 성향 | `#내향형` `#혼밥선호` `#자연선호` `#문화취향` `#초보운동` | 혼자 조용한 공간, 혼밥, 자연·문화·운동 선호 |
| 고민 | `#식단관리` `#집중회복` `#스트레스완화` `#기분전환` `#자기관리시작` | 식사·번아웃·스트레스·동기 회복 |
| 상황 | `#짧은시간` `#퇴근후` `#비오는날` `#주말오전` `#점심` | 시간대·날씨·짧은 여유 |
| 경험 강도 | `#가벼운식사` `#짧은휴식` `#걷기` `#가벼운운동` `#저자극` | 실행 부담을 가늠하는 신호 |

`scripts/tag-place-experiences.js`는 현재 Point의 카테고리와 장소명으로 보수적인 기본 태그 및 DRAFT Experience를 생성한다. 영업·혼잡도·조용함 등의 실제 경험은 현장 또는 지도 검수 후 개별 행에서 보완한다.
